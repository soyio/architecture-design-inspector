# 概要设计检查助手

[英文版](README.md)

概要设计检查助手用于检查概要设计文档中的结构性、全局性和跨系统设计决策，识别必要设计内容的缺失、设计问题及内部矛盾，并在原 Word 文档的对应位置添加简明批注，交付带批注的副本。

检查范围包括应用、数据、技术、安全、集成与运维等方面，并把握概要设计应覆盖的架构层次。使用本技能不要求文档遵循固定章节结构；检查时会区分架构层面的设计决策与应留给后续设计阶段的细节。

批注应以用户提供的文档和材料为依据。材料中无法确认的信息会作为问题提出，不会被当成既定事实。原始文档不会被覆盖，批注副本会保留已有正文、图表、批注和修订记录。

## 安装

本仓库就是技能包。对于支持从 GitHub 获取技能的智能体，可在对话框中发送以下请求：

> 请从 `https://github.com/soyio/architecture-design-inspector` 安装 `architecture-design-inspector` 技能，并在安装完成后告知我。

智能体应获取该仓库，并将技能放入自身使用的技能目录。不同平台的安装方式可能不同；如果智能体不能直接从 GitHub 安装，请按照该平台提供的技能安装流程使用本仓库。

## 使用

安装后，向智能体提供概要设计 Word 文档，并要求其使用“概要设计检查助手”技能进行检查。也可以一并提供需求、规范或相关设计材料，作为评审依据。

交付物是在原文对应位置添加简明中文批注后的 Word 副本。源文件不会被覆盖。

## 工程内容

仓库根目录就是技能包根目录：

```text
SKILL.md
agents/
assets/
references/
scripts/
```

- `SKILL.md` 说明技能的适用范围和执行方式。
- `references/content-checklist.md` 是概设内容要求的唯一维护来源。
- `references/word-comments.md` 说明 Word 批注及文档保留行为。
- `scripts/` 包含文档检查、批注和校验工具。

## 运行要求

宿主智能体需要具备文档理解能力和本地文件访问能力。运行随附脚本需要 Python 3.9 或更高版本。检查图表还需要图像查看能力。标准 DOCX 索引和批注功能仅使用 Python 标准库，不要求特定 MCP 服务。旧版 Word 文档转换和页面布局检查取决于宿主环境中可用的工具。

## 测试

在仓库根目录运行回归测试：

```bash
python -X utf8 scripts/test_rules.py
```

测试用于检查批注行为和文档保留机制，不衡量模型判断能力，也不构成对生产设计的认证。
